Compliance review assistant — 100 checks per document, human-in-the-loop on AWS

Flow

  1. 1Owner signs in and submits a document with the check set to apply.
  2. 2The document lands in the KMS-encrypted intake bucket.
  3. 3Upload starts one review execution; Textract and Comprehend prepare structured, PII-tagged text.
  4. 4A Distributed Map fans out one task per check; each retrieves criteria, judges with citations and passes through Guardrails.
  5. 5Verdict, confidence and cited spans are stored per check; the evidence bundle is written to a locked bucket.
  6. 6Only flagged checks go to a human; the execution waits on a task token.
  7. 7Reviewers confirm, override or comment; the decision resumes the execution and is recorded.
