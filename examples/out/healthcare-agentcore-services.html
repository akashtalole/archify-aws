Flow

  1. 1Staff use team-specific apps that call the API.
  2. 2Each use case is a separate agent with its own identity, scope and release cycle.
  3. 3Agents (Strands, LangGraph, CrewAI or Harness) run on AgentCore Runtime in isolated sessions.
  4. 4Agents reach tools only via Gateway, which exposes APIs and Lambda as MCP tools.
  5. 5Gateway fronts business APIs, FHIR data and knowledge bases.
  6. 6Models are called through Bedrock with Guardrails on input and output.
